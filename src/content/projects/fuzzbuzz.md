In this project we needed to work with endpoints from Noroffs API and create a social media platform. We were going to work with Tailwind CSS for the first time, and it was a little rough to become confident with it at first. For two years we had written our own CSS as usual, and now it was done in a different way. Eventually we got friends. 

The user should be able to register, log in, create new post, see other users posts, edit post, delete post, search and filter posts and log out.
