On my first React project every we were going to create a online shop. We had access to some fun data from the API, so could play around with images, text, prices AND discounted prices with percentage tags. There were also rating stars and reviews from the data for spesific products, that was fun to get into place. Looked like a real sale in the end. 

We also needed to build a shopping cart, which was were I did most of my crying... Evrything in there needed to play together, so if the user changes the number of items, the total price changed, and so on. I got it at last, and that was a great feeling!
